# 差旅与费用报销制度

## 1. 住宿标准
- 一线城市（北京/上海/广州/深圳）：每晚 500 元；
- 省会及计划单列市：每晚 400 元；
- 其他城市：每晚 350 元。
超标部分不予报销，确需超标的须在出差申请中注明并经部门总监事先审批。

## 2. 交通标准
- 高铁：单程 4 小时以内一律二等座；
- 飞机：单程 800 公里以上或高铁 6 小时以上可乘经济舱；
- 市内交通凭发票实报，单日上限 100 元。

## 3. 报销流程
1. 返岗后 5 个工作日内在 OA 系统「费用报销」发起申请；
2. 上传发票原件扫描件，发票抬头必须为公司全称；
3. 部门经理审批后流转财务复核；
4. 财务复核通过后 3 个工作日内打款至工资卡。

## 4. 常见不予报销项
- 个人消费（ minibar、洗衣、酒店电话费）；
- 无发票的纸质收据；
- 超出出差申请日期范围的费用。
