# 考勤与假期管理制度

## 1. 考勤
- 工作日 9:00-18:00，午休 12:00-13:30；
- 每月可补卡 2 次，超过需部门经理书面说明；
- 连续迟到 3 次按旷工半天处理。

## 2. 年假
- 入职满一年：5 天；
- 入职满两年：10 天；
- 入职满十年：15 天；
- 年假需提前 3 个工作日在 OA 系统提交，当年额度不可跨年累计。

## 3. 病假
- 2 天以内无需医院证明，仅需直属上级口头批准；
- 2 天以上需二级及以上医院诊断证明；
- 病假期间按当地最低工资标准的 80% 计薪。

## 4. 事假
- 事假无薪，全年累计不得超过 15 天；
- 3 天以上需提前一周申请并由总监审批。
